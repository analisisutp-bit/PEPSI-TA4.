# PEPSI: una marca global

Página web basada en la presentación **Presentación_PEPSI.pptx** (versión modificada con 10 cambios significativos).

## Contenido del repositorio
- `index.html`: página web (HTML + CSS + JS, sin dependencias externas).
- `assets/`: imágenes extraídas y optimizadas de la presentación.
- `documentos/`: PPT original, PPT modificado e instrucciones (Word).

## Cómo publicarla en GitHub Pages
1. Crear un repositorio **público** en github.com (por ejemplo `pepsi-presentacion`).
2. Subir `index.html`, `README.md`, `.nojekyll`, `assets/` y `documentos/` (Add file > Upload files) y hacer *Commit*.
3. Ir a **Settings > Pages**, elegir *Deploy from a branch*, rama `main`, carpeta `/ (root)` y guardar.
4. Esperar 1–2 minutos. El enlace será: `https://TU-USUARIO.github.io/pepsi-presentacion/`
